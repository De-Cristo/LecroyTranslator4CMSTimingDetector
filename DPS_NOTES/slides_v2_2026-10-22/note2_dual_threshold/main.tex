\TitleSlide

\begin{frame}{Abstract}
\large
Two discriminator thresholds measure a finite-interval slope on the pulse's
leading edge. A linear fit describes the mean slope as a function of charge.
Its inverse provides a time-walk model with one amplitude, AWC, per channel.
\medskip

This study measures slopes in run 4076 and determines AWC by comparison with
independent MCP calibration curves from run 4399. The fit uses only charge
intervals populated in both runs.
\medskip

The comparison tests calibration shapes, not corrected-event timing resolution.
The present AWC calibration still needs the MCP reference; reference-free
determination remains a future step.
\end{frame}

\begin{frame}{Two thresholds measure how fast the pulse rises}
\large
\textbf{Problem:} a fixed threshold gives an amplitude-dependent timestamp.
A steeper leading edge generally crosses the threshold earlier.
\medskip
\[
I_1<I_2,\qquad t_1<t_2,\qquad
S=\frac{I_2-I_1}{t_2-t_1}\quad[\mu\mathrm{A/ns}].
\]
\normalsize
\begin{enumerate}
\item Reconstruct both threshold-crossing times with consistent coarse and fine timing.
\item Divide the threshold-current separation by the crossing-time separation.
\item Use charge $Q$ to describe the mean slope for each channel.
\end{enumerate}
$S$ is a finite-interval proxy, not the instantaneous derivative or the current difference itself.
\Source{Run 4076 uses $\Delta I=7.8125\,\mu$A from the implemented threshold conversion.
\Code{Q_Walk/qwalk_core.py}{GitHub: timing and threshold reconstruction}.}
\end{frame}

\begin{frame}{3. Convert the fitted slope into a walk correction}
\large
\[
W_Q(Q)=\frac{A}{c_0+c_1Q},\qquad
t_{\rm corr}=t_{\rm measured}-W_Q(Q).
\]
\begin{itemize}
\item $A$ is AWC, a current amplitude in $\mu$A.
\item $A$ is constant for one channel and operating configuration.
\item The correction changes event by event through $Q$.
\end{itemize}
\medskip
\normalsize
The slope fit determines the charge dependence, but does not determine AWC.
The present calibration obtains AWC from an external MCP reference.
Use the model only over its calibrated charge range with a positive slope denominator.
\Source{The model concerns the mean pulse slope. Its band is not a single-hit timing uncertainty.}
\end{frame}

\begin{frame}{The slope gives the shape; the present AWC still uses MCP}
\large
\begin{enumerate}
\item Select prompt hits and fit the mean slope versus charge.
\item Form the inverse-slope walk model.
\item Fit AWC and an offset to MCP curves within measured overlap.
\item Apply the charge-dependent correction within the calibrated range.
\end{enumerate}
\normalsize
\textbf{Uncertainties:} displayed bands propagate slope-fit statistics with the MCP curve fixed.
They exclude reference-fit, model, selection and cross-run uncertainties.

\textbf{Next step:} validate corrected-event timing and determine AWC from internal information.
Shape agreement alone does not demonstrate reference-free calibration.

\end{frame}
