\begin{frame}{A single, explicit time convention}
\small
Let $g(u)$ map a scope-trigger timestamp $u$ into the TOFHIR time coordinate,
including the linear clock relation and the fitted smooth drift.
Define the within-waveform difference
\[
  \delta_{\rm MCP}=t_{\rm peak}^{\rm scope}-t_{\rm trigger}^{\rm scope}.
\]
The reference difference implemented in the calibration is
\[
 \Delta t_i=t_i^{\rm TOFHIR}-g(t_{\rm trigger}^{\rm scope})
                    -\delta_{\rm MCP},
\]
up to a fixed cable and geometry offset. The clock-rate correction for the
short within-waveform interval is negligible and is omitted.

The charge-dependent component of $\Delta t_i$ is the time walk.
An arbitrary constant does not change a shape calibration.\par
{\scriptsize\textbf{GitHub implementation:}
\RepoFile{TimeCalibration/ch192_vs_trigger_lowess.py\#L816}{per-file subtraction};
\RepoFile{TimeCalibration/ch192_vs_trigger_lowess.py\#L1102}{combined-run subtraction}.
Both per-file and combined-run calculations subtract
\texttt{(mcp\_peak - mcp\_trig)}.\par}
\end{frame}

\begin{frame}{Clock quality before timing validation}
\small
Segment boundaries are identified from consecutive finite scope timestamps,
including resets across missing entries. Nonfinite trigger times have no valid mapping.

For each topology, file and segment, fit channel 192 against the scope trigger.
Reject the whole group if the line-residual scale $1.4826\,\mathrm{MAD}$ exceeds
1\,ns, before LOWESS. This rule uses clocks only, not SiPM arrival times.

Six bar-8 groups with finite trigger times fail this cut. Changing the threshold
from 1\,ns to 1\,$\mu$s retains the same groups. Suspected one-event association
offsets are excluded; MCP rows are not shifted to repair them.

Refit the channel walk curves after this selection. For the following timing
comparison, both ends must pass the quality and lower-charge cuts. Each end
must also lie within its populated reference bins and outer profile means.
No additional selection is made on either timing-difference observable.

\end{frame}

\begin{frame}{What these timing widths establish}
\small
The reproduced distributions compare timing performance before and after
correction under fixed selections and calibrations. They do not measure
intrinsic bar resolution or isolate synchronization jitter.
At fixed position, for end timing errors $e_L,e_R$,
\[
\mathrm{Var}\!\left(\frac{e_L+e_R}{2}\right)
=\frac{\mathrm{Var}(e_L-e_R)}{4}+\mathrm{Cov}(e_L,e_R).
\]
Halving an end-difference width requires controlled position effects and
negligible end-error covariance. Shared MCP and clock errors also prevent
inferring detector covariance directly from the measured reference residuals.

Separately fitted core widths cannot be treated as variances of a common model
to infer synchronization jitter by quadrature subtraction.
This version reports same-event timing validation with conditional statistical
intervals. Intrinsic bar resolution and synchronization-jitter extraction are
outside its scope. Position, covariance, segment-offset and calibration
systematics are not included in the quoted intervals.
\end{frame}

\begin{frame}{Reference-calibration result and scope}
\small
\begin{itemize}
\item A trigger link enables calibration with common events across independent
BTL and oscilloscope time coordinates.
\item A linear clock relation plus a smooth residual correction defines
the reference-time mapping.
\item Four clock-corrected inverse-charge profiles and quadratic functions
provide the reference used in Note 2. The archived fits remain as a comparison;
profile points, SEM and both coefficient sets accompany this draft.
\item Intrinsic MCP timing, reference-bar timing and cross-system
synchronization are different performance quantities.
\item Charge range and operating conditions limit transfer to other
samples; a constant time offset is not a walk-shape difference.
\end{itemize}
\medskip
For the same selected events, walk correction reduces the bar--MCP core width
from \RBefore{} to \RAfter\,ps. This is a conditional timing-validation result,
not an intrinsic-resolution measurement or a complete uncertainty budget.
\end{frame}
