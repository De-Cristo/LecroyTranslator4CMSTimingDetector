\newcommand{\DPCoverAbstract}{%
Several analyses of the 2025 data set benefit from an external time reference
($t_0$). During the testbeam period a Hamamatsu MCP-PMT was placed downstream of
the setup and waveforms were digitized on a Lecroy scope. Since the active area
($\emptyset$=10mm ) of the PMT only covered a couple BTL bars under test and the
scope DAQ captured only 7.5k events per spill, we used a limited data set to
calibrate Reference Bar timing relative to the MCP (which had intrinsic
resolution of 7.5 picoseconds). The calibration functions are provided in this note.}
\newcommand{\DPAbstract}{%
This study examines a timing-calibration procedure for CMS barrel timing layer
(BTL) prototype scintillator bars using September 2025 beam-test data. A microchannel-plate
photomultiplier (MCP-PMT), digitized by an oscilloscope, provides an external
arrival-time reference. A trigger link identifies coincident events in the
BTL readout and the oscilloscope. Segment-dependent clock alignment and
locally weighted smoothing map the reference into the BTL time coordinate.

Quadratic functions of inverse charge describe the charge dependence of the
measured arrival time for four silicon-photomultiplier channels on two reference
bars. These functions provide an empirical time-walk
calibration over the measured charge range. Clock-corrected profiles provide
the reference for the companion dual-threshold study; archived fits are
retained to document the change in calibration procedure. Timing-difference
distributions illustrate the validation strategy. Their interpretation separates
intrinsic reference-detector resolution from residual synchronization effects.
This draft presents the results and the selection, uncertainty and
reproducibility checks that remain before publication.}
