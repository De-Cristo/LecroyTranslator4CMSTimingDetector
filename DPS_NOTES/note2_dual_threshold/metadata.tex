\newcommand{\DPCoverAbstract}{%
With new high intrinsic precision timing detectors for the HL-LHC upgrades,
the strategy for commissioning these detectors must differ from previous collider
experience. Prior to LHC, collider experiments benefitted from a clear timing
reference for use in calibration of the detectors. At low luminosity an
interaction trigger was useful for rejecting background but also fulfilled this
role. For the ATLAS and CMS upgrades, an interaction trigger would be superfluous
since they are designed for 140-200 interactions per trigger event. Dual threshold
timing enables a calibration strategy when a $t_0$ reference is not readily
available. We extend an earlier bench test demonstration of this technique with
the CMS Barrel Timing Layer(BTL) sensors and the TOFHIR readout ASIC to a 180 GeV
pion beam exposure. These data confirm the earlier single coefficient correction
for walk and the conclusion that walk calibration to the required $\sim 10\%$
precision is practical with simple data sets using only this system with beam or cosmic rays.}
\newcommand{\DPAbstract}{%
This study examines a charge-dependent time-walk model for CMS barrel timing
layer (BTL) prototype channels using two discriminator thresholds. The current
separation divided by the measured crossing-time separation provides a
finite-interval pulse-slope proxy. A linear profile fit describes this
proxy as a function of the measured charge, and an inverse-slope function
models the timing correction with one amplitude parameter per channel.

The comparison uses slope measurements from run 4076 and independent
microchannel-plate (MCP) reference calibrations from run 4399. The two runs
contain different events. A fit determines a free constant offset and the
correction amplitude only in charge intervals populated in both measurements.
This is a comparison of calibration shapes, not an independent
measurement of timing resolution.

The draft also examines channel-to-channel variations and an exploratory
model that predicts the correction amplitude from internal pulse information.
This model could enable operation without an event-by-event external time
reference. Its transferability and full uncertainty remain to be established.}
