\begin{frame}{From two crossing times to a walk model}
\small
For thresholds $I_1<I_2$ and their valid crossing times $t_1,t_2$, define
\[
 S=\frac{I_2-I_1}{t_2-t_1}\quad [\mu{\rm A/ns}],\qquad
 \overline S(Q)\simeq c_0+c_1Q.
\]
$S$ is a finite-interval rising-edge slope proxy. It is not the current
difference $\Delta I$ itself and is not necessarily the instantaneous
derivative at the first threshold.
\[
 W_Q(Q)=\frac{A}{c_0+c_1Q},\qquad t_{\rm corr}=t_{\rm measured}-W_Q(Q).
\]
The amplitude $A$ (AWC) has units of current and is constant for a channel
and operating configuration. The correction varies event by event through $Q$.
\Review{N2-2}{Freeze the safe-$t_2$ decoding, threshold conversion and physical
timing cuts. This is an effective pulse model, not an exact waveform identity.}
\end{frame}

\begin{frame}{Selection and profile construction}
\small
\begin{itemize}
\item Run 4076: require exactly the two hits of the target bar in its module.
Hits in the other module are not constrained; channel 192 is ignored.
\item Retain valid rising-edge timing and the selected prompt-slope population,
removing unphysical and slow-slope events before profiling.
\item Retain charge above the lower half-maximum boundary of the fitted
Landau--Gaussian peak. The selected data extend to the right of the peak.
\item Form ten charge bins. Plot the mean $S$ and the hit standard deviation
(SD); use the standard error of the mean (SEM) for the linear-fit weights.
\item Bootstrap the selected hits with fixed charge-bin edges and refit.
The central 68\% interval uses the 16th and 84th percentiles of 1000 fits;
Ref.~\cite{Bootstrap} describes the general resampling principle.
\end{itemize}

newer code defaults. These full-statistics profiles are not train/test splits.}
\end{frame}

\begin{frame}{Determine AWC using only jointly measured support}
\small
The run-4399 reference is a fitted quadratic in inverse charge,
\[
 W_{\rm MCP}(Q)=a+b/Q+c/Q^2.
\]
Let $\Omega$ be the intersection of the two outer profile-mean ranges,
restricted to charge bins populated in both runs. Fit
\[
 (A,B)=\arg\min_{A,B}\sum_{Q_k\in\Omega}
 \left[\frac{A}{c_0+c_1Q_k}+B-W_{\rm MCP}(Q_k)\right]^2.
\]
The saved implementation samples a uniform 3000-point charge grid before
removing unsupported intervals. The offset $B$ absorbs the arbitrary time zero.

This is uniform-charge shape matching, not an event-weighted likelihood.
It uses neither extrapolated tails nor a single central anchor point.
\Review{N2-4}{Compare weighting alternatives and propagate reference-fit
uncertainty. The current objective is a documented choice, not a uniquely
optimal estimator.}
\end{frame}

\begin{frame}{Result and next validation step}
\small
\begin{itemize}
\item A dual-threshold measurement provides a charge-dependent slope proxy;
an inverse-slope function can be aligned to independent MCP walk curves.
\item Restricting alignment to jointly measured charge support avoids
determining AWC from extrapolation.
\item Reference-calibrated AWC varies between channels. A straight line
against $1/c_1$ is insufficient for the explored subset.
\item The present calibration still uses the MCP to determine AWC.
It does not establish reference-free AWC extraction by itself.
\item An internal predictor must be tested on held-out bars/configurations
with transfer and target uncertainties included before use without MCP.
\end{itemize}
\medskip
The following backup explores such a predictor; it is not a final
performance claim or a demonstration with cosmic rays.
\end{frame}

\begin{frame}{Backup: an internal predictor for channel AWC}
\small
For $W=A/S$ and $S=c_0+c_1Q$,
\[
 -\frac{dW}{d\ln Q}=\frac{A\,c_1Q}{S(Q)^2}.
\]
If this local walk derivative is approximately shared between channels at
a prescribed typical charge $Q_*$, a candidate model is
\[
 A_{\rm pred}=K\,\frac{S(Q_*)^2}{c_1Q_*}.
\]
Here $Q_*$ is the median charge of the run-4076 quality- and peak-right-selected
sample. It is computed once per channel; $A_{\rm pred}$ remains constant
when correcting individual events.

The common $K$ is learned from MCP-calibrated training channels. Predicting
a new channel uses internal features, but the model development is reference-based.
\Review{N2-7}{Shared local derivative is a hypothesis. Test operating-condition
dependence and avoid selecting $Q_*$ only after inspecting prediction scores.}
\end{frame}
